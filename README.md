# HZ HUB — Roblox Automation

ฮับอัตโนมัติสำหรับ Roblox — **คีย์ชุดเดียวใช้ได้ทุกแมพ**

## ติดตั้ง (เทสเตอร์) — วิธีง่ายสุด

วางบรรทัดนี้ใน executor แล้วกดรัน (ไม่ต้องโหลดไฟล์):

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/thanadol8821/hzhub/main/releases/hz_valley.lua"))()
```

→ หน้าคีย์เด้ง → ใส่ **`123`** → กด "ยืนยันคีย์" → เล่น

## ฟีเจอร์ (Huss Valley)

- **อัตโนมัติเต็มรอบ** — เล่นจริงได้ทั้งสองฝั่ง: วิ่งหนีเข้าโซน / วิ่งไล่จับเหยื่อ
- **GOD** — อ่าน telegraph ของตัวไล่ทุกเฟรม หลบอัตโนมัติ
- **ชุบตัวเอง** — RescueKit กู้กลับมาเล่นต่อได้
- **ESP** — กรอบสีรอบตัวทุกคน: แดง=ตัวไล่ น้ำเงิน=ตัวหนี
- **Auto-everything** — เลือกฮีโร่ / โหวตแมพ / เคลมของฟรี / ซื้อเกียร์
- UI ไทยล้วน รองรับมือถือ มีคู่มือในตัว
