# HZ HUB — Roblox Automation

ฮับอัตโนมัติสำหรับ Roblox — **คีย์ชุดเดียวใช้ได้ทุกแมพ**

## ติดตั้ง (เทสเตอร์)

1. เลือกไฟล์ตามแมพที่จะเล่น:
<!--FILES-->
| แมพ | ไฟล์ใน releases/ |
|---|---|
| Chicken or Hero (Huss Valley) | `releases/hz_valley.lua` |
<!--/FILES-->
2. วางไฟล์ไว้ในโฟลเดอร์ workspace ของ executor (เช่น Xeno: `%LOCALAPPDATA%/Xeno/workspace/`)
3. เข้าเกม → executor inject → รัน:
   ```lua
   loadstring(readfile("hz_valley.lua"))()   -- เปลี่ยนชื่อไฟล์ตามแมพ
   ```
   หรือวางใน autoexec ให้รันเอง
4. หน้าคีย์เด้งขึ้นมา → ใส่คีย์ → กด "ยืนยันคีย์"

## ฟีเจอร์ (Huss Valley)

- **อัตโนมัติเต็มรอบ** — เล่นจริงได้ทั้งสองฝั่ง: วิ่งหนีเข้าโซน / วิ่งไล่จับเหยื่อ
- **GOD** — อ่าน telegraph ของตัวไล่ทุกเฟรม หลบอัตโนมัติ
- **ชุบตัวเอง** — RescueKit กู้กลับมาเล่นต่อได้
- **ESP** — กรอบสีรอบตัวทุกคน: แดง=ตัวไล่ น้ำเงิน=ตัวหนี
- **Auto-everything** — เลือกฮีโร่ / โหวตแมพ / เคลมของฟรี / ซื้อเกียร์
- UI ไทยล้วน รองรับมือถือ มีคู่มือในตัว
